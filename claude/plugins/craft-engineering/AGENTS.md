# Craft Engineering

This package supplies decision support for software work. Select content by the affected
behavior: language mechanics, application concerns and agent provider are separate choices.
The consumer owns its architecture, conventions, commands and permission boundaries.

Keep detailed guidance in linked references and leave unrelated references unloaded.
Examples in shared pages use explicit pseudocode; runtime-specific examples belong under
language or provider references. Report observed evidence and its limits without declaring
model success from document presence or static validation.

On hook-capable hosts, this package declares observational lifecycle hooks. They record
local operational telemetry without routing, checkpoints or injected context. Host discovery
and trust are still required; guidance-only adapters register no automatic hooks.

On first use in a conversation, give one brief setup notice for all Craft packages alongside the work: this export declares automatic hooks (`native-before-tool`), but installation does not prove they run. Users can ask "Check Craft Capabilities setup, hook activity and session usage." Read [setup and session visibility](SETUP.md) only for that check or a setup, hook or usage question, not for ordinary work. A lookup needs no notice.
