# Select applicable guidance

Read the consumer's accepted instructions and affected build/runtime configuration. Identify the
language changed, application layer, framework and provider as separate facts. Use the shared router
when available and verify its declarations against actual source; path inference is a lead rather
than authoritative configuration.

Return the relevant logical skill/reference targets with their evidence and unresolved conflicts.
Use project policy when generic advice differs and report missing specialization instead of inventing
it. Selecting guidance executes no task, creates no connection and grants no new permission.
