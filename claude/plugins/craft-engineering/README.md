# Craft Engineering

Use this package when a software task needs engineering decisions grounded in an actual
repository. It covers shared design, six languages, backend reliability, browser interfaces,
security, verification and model-driven systems.

Begin with `foundations` for cross-cutting changes. Choose `backend-foundations` or
`ui-foundations` when that application boundary matters; their deeper engineering indexes
lead to focused references. React guidance requires a React implementation. `design-agent`
and `evaluate-agent` address model-driven behavior without assuming its provider.

`locate-code` produces scoped evidence before expensive reasoning. It favors one bounded
search batch and permits an economical worker only when the host and user authorize it.
Language, framework, runtime and cloud remain independent selections.

The consumer's accepted policy takes precedence over generic advice. Source documents and
generated host bundles are different artifacts; builds do not install tools, activate
connections or establish that a host has executed a workflow successfully.

## Claude Code install

After adding the generated marketplace:

```text
/plugin install craft-engineering@craft-capabilities
```
