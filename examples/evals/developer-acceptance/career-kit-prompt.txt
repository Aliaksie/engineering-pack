Add validation for required profile fields in the offline CLI.
When generating a CV/profile, validate that the input contains:
- a non-empty name (person.name)
- at least one experience entry (experiences)

1. Invalid input exits with a non-zero status and a clear message identifying the missing field.
2. Valid existing input continues to generate exactly as before.
