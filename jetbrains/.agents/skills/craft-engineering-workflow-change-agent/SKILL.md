# Change an agent deliberately

Use `craft-engineering-design-agent` to specify the intended behavior, trusted effects and state
ownership. Resolve language, runtime and provider independently, then make the focused change without
expanding tool authority or adding unrelated deployment work.

Use `craft-engineering-evaluate-agent` to compare matched inputs for relevant prompt/model/retrieval
or orchestration changes. Include malformed output, repeated calls and a denied effect when applicable.
Retain real outputs and acceptance evidence; deterministic checks cannot establish model benefit.

Return the resulting behavior, observed verification, regressions and unavailable evidence. Existing
authorization controls deployment, model switches and additional workers.
